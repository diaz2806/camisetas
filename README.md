# Camisetas

Web (PWA) para llevar las cuentas de los pedidos de camisetas: lo que se paga al proveedor, lo que paga cada persona y lo que queda pendiente.

- Tres catálogos de precios: Amigos del primo, Amigos y Familia.
- Comisión de PayPal por pedido y extra por persona.
- Los datos se guardan en el propio móvil (localStorage). Exporta una copia de seguridad desde la pestaña Catálogos.
